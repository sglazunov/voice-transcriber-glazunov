# 🖥️ Voice Transcriber — десктоп-версия

Эта ветка (`desktop`) — то же самое приложение, что и веб-версия (`main`), но
запускается **как обычная программа в отдельном окне**, а не во вкладке
браузера. Весь код в `app/` идентичен веб-версии; десктоп добавляет только
оболочку и сборку.

| | Веб-версия (`main`) | Десктоп-версия (`desktop`) |
|---|---|---|
| Запуск | `run.bat` → браузер на `localhost:8000` | окно-программа |
| Оболочка | браузер | нативное окно (Edge WebView2) |
| Бэкенд | FastAPI + faster-whisper | **тот же самый** |
| Установка | вручную | один установщик (+ Ollama) |

---

## Как запустить (для разработки)

```bat
:: один раз — окружение и зависимости (Python 3.12!)
install.bat
.venv\Scripts\python -m pip install -r requirements-desktop.txt

:: запуск как программы (откроется окно)
run_desktop.bat
```

`desktop.py` сам поднимает локальный сервер на свободном порту, стартует Ollama
(если установлена) и открывает нативное окно. Проверить, что сервер работает,
без открытия окна: `python desktop.py --selftest`.

## Как собрать установщик (.exe)

1. **Собрать программу в .exe:**
   ```bat
   build_desktop.bat
   ```
   Результат — папка `dist\VoiceTranscriber\` с `VoiceTranscriber.exe`
   (PyInstaller, onedir; включает Python, FastAPI и движок распознавания).

2. **Собрать установщик:** установите [Inno Setup](https://jrsoftware.org/isdl.php),
   откройте `installer.iss` и нажмите **Compile**. Получится
   `VoiceTranscriber-Setup.exe`.

Установщик:
- ставит программу и создаёт ярлыки (меню «Пуск» + рабочий стол);
- **всегда ставит Visual C++ Redistributable** (нужен распознаванию при любом
  движке) — пропускает, если уже установлен;
- по галочке **доустанавливает Ollama и качает модель** `qwen2.5:7b`
  (через `setup_ollama.bat`) — для протоколов оффлайн;
- предлагает запустить программу по завершении.

> **Системный Python не нужен.** Он вшит в `.exe` (PyInstaller) — конечному
> пользователю Python ставить не требуется. Python 3.12 нужен только на машине
> сборки (его поставит `install.bat`).

> **VC++ надёжнее всего вшить.** Скачайте `VC_redist.x64.exe`
> (https://aka.ms/vs/17/release/vc_redist.x64.exe) и положите рядом с
> `installer.iss` перед компиляцией — тогда он ставится из комплекта (с UAC).
> Если файла нет, установщик ставит VC++ через winget.

> **Почему Ollama ставится отдельно, а не «вшита» в .exe.** Ollama (~700 МБ) и
> модель (~4.7 ГБ) — внешние компоненты; вшивать их в установщик непрактично
> (гигабайты). Установщик ставит их как зависимость — для пользователя это всё
> равно «один установщик → готовая программа».

## Синхронизация с веб-версией

Общий код живёт в `app/`. Чтобы перенести изменения между ветками:

```bat
:: подтянуть правки бэкенда из main в desktop
git checkout desktop
git merge main

:: или наоборот — фичу из desktop (только app/) в main
git checkout main
git checkout desktop -- app/
```

Файлы только десктопа (`desktop.py`, `run_desktop.bat`, `build_desktop.bat`,
`VoiceTranscriber.spec`, `installer.iss`, `setup_ollama.bat`,
`requirements-desktop.txt`) в `main` не нужны.
