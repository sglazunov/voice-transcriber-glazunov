# 🎙️ Voice Transcriber

Веб-сервис распознавания речи на **faster-whisper**. Загружаешь **аудио или
видео** (до 2 ГБ) через сайт или API — текст печатается **прямо во время
распознавания**, с прогрессом и таймером. Результат: TXT / SRT / JSON.

Принцип: **одна задача за раз** (один фоновый воркер), модель грузится в память
один раз — чтобы не перегружать машину.

## Возможности
- Живой интерфейс: текст появляется по мере распознавания, прогресс-бар, таймер.
- Загрузка аудио и видео (mp3/wav/m4a/ogg/opus · mp4/mkv/webm/mov), до 2 ГБ.
  Аудиодорожка из видео извлекается автоматически — отдельный ffmpeg не нужен.
- REST API (`/api/jobs`).
- Форматы результата: TXT (с таймкодами), SRT (субтитры), JSON.
- Языки: ru / en / uk / авто.
- Диаризация (кто говорил) — опционально (нужен HF-токен и пакет pyannote).

## 🚀 Быстрый старт на Windows 11
1. Установи **Python 3.10+** с https://www.python.org/downloads/
   (при установке отметь галочку **«Add Python to PATH»**).
2. Двойной клик по **`install.bat`** — поставит зависимости и скачает модель
   (один раз, ~0.5 ГБ).
3. Двойной клик по **`run.bat`** — откроет браузер на http://localhost:8000

С других устройств в той же сети: `http://<IP-этого-ПК>:8000`
(узнать IP: `ipconfig` → строка IPv4).

> Рекомендуется для машины 16 ГБ RAM / SSD: модель `small` (по умолчанию) даёт
> хороший русский. Хочешь точнее — поставь переменную `VTX_MODEL=medium`
> (медленнее, ~3 ГБ RAM). См. таблицу настроек ниже.

## Linux (вариант для сервера)

## Требования
- Ubuntu/Debian, Python 3.10+
- ffmpeg
- ~1.5 ГБ свободной RAM на саму модель `small`

## Установка (на сервере)
```bash
# скопировать папку на сервер, затем:
cd ~/voice-transcriber
bash deploy.sh
```
`deploy.sh` поставит ffmpeg, создаст venv, установит зависимости и заранее
скачает модель.

## Запуск вручную
```bash
cd ~/voice-transcriber
source .venv/bin/activate
uvicorn app.main:app --host 0.0.0.0 --port 8000
```
Открыть с любого устройства в той же сети: **http://192.168.0.63:8000/**

## Автозапуск (systemd)
```bash
sudo cp voicetx.service /etc/systemd/system/
# при необходимости поправьте User= и пути внутри файла
sudo systemctl daemon-reload
sudo systemctl enable --now voicetx
sudo systemctl status voicetx
journalctl -u voicetx -f      # смотреть логи
```

## REST API
```bash
# создать задачу
curl -F "file=@meeting.mp3" -F "language=ru" http://192.168.0.63:8000/api/jobs
# -> {"job_id":"abc123...","status":"queued",...}

# статус
curl http://192.168.0.63:8000/api/jobs/abc123

# результат (txt | srt | json)
curl "http://192.168.0.63:8000/api/jobs/abc123/result?format=txt"
```

## Точность имён и терминов
Распознавание автоматическое — собственные имена/фамилии и узкие термины
модель угадывает по звучанию и часто искажает. Два встроенных способа исправить
(раскрой в форме блок «🎯 Точность: имена и термины»):

1. **Известные имена и термины** — список через запятую (имена, фамилии,
   названия продуктов). Модель получает их как подсказку (`initial_prompt`) и
   начинает писать правильно.
2. **Замены «как слышится → правильно»** — по одной паре на строку, чинит
   повторяющиеся ошибки гарантированно (применяется после распознавания):
   ```
   Конид = Коновалов
   джиэрписи -> gRPC
   кафка → Kafka
   ```
   Замены — по целым словам и без учёта регистра.

Для максимума можно ещё взять модель крупнее (`VTX_MODEL=large-v3`).

## Настройка (переменные окружения)
| Переменная | По умолчанию | Описание |
|---|---|---|
| `VTX_MODEL` | `small` | `tiny`/`base`/`small`/`medium`/`large-v3` |
| `VTX_COMPUTE_TYPE` | `int8` | точность вычислений (`int8` — экономно) |
| `VTX_CPU_THREADS` | `4` | число потоков (= числу ядер) |
| `VTX_BEAM_SIZE` | `1` | 1 = быстро (greedy), 5 = точнее |
| `VTX_LANGUAGE` | `ru` | язык по умолчанию |
| `VTX_MAX_UPLOAD_MB` | `500` | лимит размера файла |
| `VTX_DIARIZATION` | `0` | `1` — включить разбивку по говорящим |
| `HF_TOKEN` | — | токен HuggingFace (нужен для диаризации) |

## Производительность на этом железе
Pentium N3710 — слабый CPU. Ориентир для модели `small`, `int8`:
запись ~80 минут обрабатывается **десятки минут**. Если нужно быстрее и
качество не критично — поставьте `VTX_MODEL=base`. Для лучшего качества и
диаризации потребуется апгрейд RAM до 8 ГБ.

## Диаризация (кто говорил) — позже
Сейчас выключена осознанно: pyannote + torch не помещаются в 4 ГБ рядом с
Whisper. После апгрейда RAM:
```bash
source .venv/bin/activate
pip install pyannote.audio torch
export HF_TOKEN=hf_xxx           # принять условия модели на huggingface.co
export VTX_DIARIZATION=1
```
и перезапустить сервис. В веб-форме появится галочка «Разбивка по говорящим».

## Доступ извне (по желанию)
Сервер на домашней локалке (192.168.0.63). Чтобы открыть доступ снаружи
безопасно — используйте туннель вместо проброса портов:
- **Tailscale** — приватная сеть, проще всего;
- **Cloudflare Tunnel** — публичный HTTPS-адрес без открытия портов роутера.
